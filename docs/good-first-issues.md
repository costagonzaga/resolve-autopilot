# Ideas for first contributions

1. Test `resolve-autopilot check` on macOS and report the output (fix paths if needed).
2. Test on Linux (`/opt/resolve`) and report.
3. Add `--look-file look.json` to load zoom and CDL values from a file.
4. Captions: drive Resolve's Auto Captions or a Text+ template through the API.
5. Add a `--dry-run` to `mix` that only prints the planned SFX events.
6. Export an EDL/FCPXML check after `look`, to confirm the cuts did not move.
7. Recipe: podcast clip (vertical crop from a horizontal interview).
8. Detect and cut silences before building the timeline.
